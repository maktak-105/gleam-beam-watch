# 計画書: ブラウザで開いた結果を死活にする(v1.0)

## 目的

AI195417 で動いている BEAM Watch の死活を、「ブラウザで URL を開いてページが出たか」にする。ページが出れば OK、出なければ NG。HTTP の状態コードでは決めない。

## 現状分析

- 稼働中の `C:\server\Apps\beam-watch` は、HTTP クライアントの状態コードで判定している。2xx と 3xx が OK、4xx と 5xx と接続失敗が NG。ブラウザは起動しない。`fieldstyle-nav.vercel.app` はブラウザでは FieldStyle のページが出るが、Vercel の 403 を NG にしている。
- ローカルの `src/beam_watch.gleam` は書きかけで、`https://` だけ `deploy/server/BrowserCheck.ps1` 経由の Edge に渡し、それ以外は従来の状態コード判定のまま。export も publish もしていない。
- `deploy/server/BrowserCheck.ps1` は Edge のヘッドレスでページを取り、1行出す。ページが取れてボット確認画面でなければ `OK`。確認画面のまま、時間切れ、取得失敗は `NG` と理由。
- `src/gui_server.gleam` の `check_all` は登録対象を全部同時に起動する。`check_wait_ms` は 120秒、`check_attempts` は 3。
- 画面は登録全件の最新 OK/NG。対象一覧は出さない。ローカルの `gui/script.js` は `detail` を表示する書きかけ。サーバーへは未反映。
- 監視対象は 49件、自動確認の間隔は 300秒。`deploy/Publish-ToServer.ps1` は、サーバーに `gui/settings.json` があるときは上書きしない。

## 変更内容

- `src/beam_watch.gleam`: 登録された URL はすべて、ブラウザで 1回開いた結果だけを死活にする。状態コードによる OK/NG は使わない。`OK` の1行が返ったときだけ OK。それ以外は NG とし、返ってきた理由を残す。
- `src/gui_server.gleam`: ブラウザの同時起動を 4件までに制限する。49件を一度に開かない。1件の待ちはブラウザ側の 40秒に合わせる。
- `deploy/server/BrowserCheck.ps1`: 判定文面は「ページが出た = OK」に揃える。判定条件（ページが取れる、ボット確認画面のままは NG）は維持する。
- `gui/script.js`: 各行に OK/NG と、その理由を出す。
- `README.md`: 判定の説明を、ブラウザでページが出たか、に直す。
- 変更しないもの: サーバーの `gui/settings.json`（対象 49件と間隔）、画面の全件表示、対象一覧を戻さないこと、待受ポート 8010、タスク名 `Beam-watch`。

## 検証方法

1. `gleam test` が通る。
2. `gleam export erlang-shipment` のあと `deploy/Publish-ToServer.ps1` で AI195417 へ置く。既存の `settings.json` は残す。
3. タスク `Beam-watch` のプロセスだけ止めて、起動し直す。
4. `http://AI195417:8010/api/targets` が 49件のままである。
5. 確認後の `http://AI195417:8010/api/results` で、`https://fieldstyle-nav.vercel.app/` が OK、理由がページが出た旨である。NG の行は、状態コードではなくブラウザが開けなかった理由になっている。

## リスク

- タスクは SYSTEM で動く。SYSTEM で Edge が起動できないと全件 NG になる。全件の前に、SYSTEM で `fieldstyle-nav` を1件開いてページが出ることを確認する。出なければ全件反映の前に止めて、この計画を改版する。
- 49件をブラウザで開くと、1周が 300秒を超える可能性がある。同時 4件、1件の上限は約 40秒。超えた場合は、その計測を結果に書き、対象の分け方は改版する。
- サーバーの待受ポートの多くは、ブラウザでページが出ない。その行は NG になる。これはこの仕様どおりで、ポートのプロセスが落ちたという意味にはしない。理由に「ページを取得できない」等を出す。
